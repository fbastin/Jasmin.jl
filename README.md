# Jasmin
Just Another Simplex Minimizer

> **This project is archived and no longer maintained.**
>
> Jasmin is a small dense-tableau simplex implementation written for
> experimentation. Its MathOptInterface wrapper is incomplete and it is not
> suitable for solving real problems.
>
> For linear programming in Julia, use [JuMP](https://jump.dev) with
> [HiGHS.jl](https://github.com/jump-dev/HiGHS.jl), or
> [Tulip.jl](https://github.com/ds4dm/Tulip.jl) for a pure-Julia solver
> supporting arbitrary numeric types.
